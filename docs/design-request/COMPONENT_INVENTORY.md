# Component Inventory

For every component below, the design package must specify purpose, inputs,
variants, states, accessibility semantics, light/dark appearance, dynamic
type behavior, and screen usage.

## Shell and navigation

- App shell
- Top app bar
- Bottom navigation or navigation rail
- Vehicle switcher
- Back navigation behavior
- Screen title and context treatment

## Vehicle and dashboard

- Vehicle card
- Active-vehicle indicator
- Metric card
- Summary card
- Quick-action control
- Reminder status card
- Recent-activity row
- Stale-odometer banner

## Forms

- Text field
- Multiline notes field
- Numeric field
- Currency field
- Date picker
- Month/date interval control
- Unit selector
- Currency selector
- Fuel-kind selector
- Category selector
- Record-type selector
- Checkbox/switch
- Receipt attachment control
- Form section header
- Inline validation message

## Lists and filters

- Fuel-entry row
- Expense-record row
- Reminder row
- Detail header
- Filter chip
- Filter sheet
- Search field
- Sort control
- Swipe/action affordance if used

## Feedback

- Loading state
- Empty state
- Error state
- Warning banner
- Status badge
- Confirmation dialog
- Delete dialog
- Import report summary
- Snackbar/message strategy

## Statistics

- Chart container
- Chart legend
- Date-range selector
- Metric summary
- Accessible chart text alternative
- No-data chart state
- Invalid-data explanation
