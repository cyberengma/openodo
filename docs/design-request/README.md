# OpenOdo Design Request Package

This package is the request sent to UI/design agents before the OpenOdo
application-shell and UI slices are authored.

Read in this order:

1. `UI_AGENT_REQUEST.md` — assignment and non-negotiable constraints.
2. `PRODUCT_CONTEXT.md` — product, domain, and platform context.
3. `SCREEN_REQUIREMENTS.md` — required screens and flows.
4. `COMPONENT_INVENTORY.md` — reusable component requirements.
5. `STATE_AND_INTERACTION_REQUIREMENTS.md` — state, navigation, and behavior rules.
6. `ACCESSIBILITY_REQUIREMENTS.md` — accessibility and responsive requirements.
7. `DESIGN_DELIVERABLES.md` — expected output format.
8. `ACCEPTANCE_CHECKLIST.md` — completion gate.
9. `handoff-template.md` — final design-agent response template.

The approved result becomes the authority under `docs/design/`. It will be
used to author the missing Slice 06–10 briefs. This package is a design
request, not an instruction to write Compose code.
