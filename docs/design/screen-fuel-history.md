# Fuel History

Show a chronological, month-grouped fuel timeline. Each row shows station or
label, date, odometer, volume/energy, cost, full/partial state, missed-fill
state, and economy when valid.

Filters: liquid/electric, fuel label, date range, full tank, missed fill.
Support search or station filtering where space allows. Detail supports edit
and delete with confirmation. Invalid imported rows show their report status
instead of pretending to be complete.

Empty state: add the first fuel entry. Loading uses list skeletons. Errors
offer local retry. Accessibility exposes all row metrics in reading order.
