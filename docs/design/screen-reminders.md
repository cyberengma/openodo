# Reminders

Reminder cards show type, interval configuration, next due date/odometer,
remaining days/distance, trigger axis, and status: OK, Due Soon, Overdue,
Inactive, or Unanchored.

Sort overdue first, then due soon, then OK; ties use remaining value and id.
Use icon, label, text, and ordering in addition to color. Stale odometer is
a separate warning. Empty state explains that reminders can be anchored by a
matching expense or manual reset.
