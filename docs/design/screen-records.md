# Records

Use one unified timeline for Service, Repair, Upgrade, and Other records.
Rows show category/type, title, date, odometer, cost, performed-by, shop,
warranty, receipt, and notes indicators.

Filters: category, type, date range, shop. Search covers title, description,
and shop. Detail exposes edit/delete and reminder-reset context. Empty state
offers Add Expense. Imported records may show an import-origin note.
