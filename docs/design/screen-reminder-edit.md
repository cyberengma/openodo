# Reminder Detail and Edit

Create/edit fields: reminder type, distance interval, month interval, active
state, anchor date, and anchor odometer. At least one positive interval is
required. Both intervals use whichever comes first.

Detail shows current state, due values, remaining values, trigger axis, stale
odometer warning, current anchor, and reset history/context. Actions are edit,
manual reset, deactivate, and delete. Logging a matching expense should be
explained as automatic anchor reset; deleting the latest matching record may
re-anchor or clear it.
