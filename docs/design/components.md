# Components

## Shell

Top app bar, active vehicle switcher, bottom navigation, section header,
screen-level loading skeleton, snackbar/message, and confirmation dialog.

## Data display

Vehicle card, metric card, reminder status card, activity row, fuel row,
expense row, detail header, status badge, unit/currency value, filter chip,
filter sheet, date-range control, and chart card.

## Forms

Text/multiline field, numeric field with unit suffix, currency field, date
picker, interval control, vehicle-scoped configuration selector, fuel-kind
selector, category/type selector, switch/checkbox, receipt attachment, inline
validation, and save bar.

Every component requires loading, disabled, focused, error, warning, dark,
large-text, and accessibility variants where applicable.
