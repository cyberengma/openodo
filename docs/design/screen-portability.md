# Portability

The portability hub offers JSON backup restore/export, CSV export, Drivvo
import, and Fuelio import. Before applying data, show the operation and
vehicle scope, then show imported, warning, and skipped counts with report
codes and row detail.

Handle malformed CSV, unsupported schema, duplicate application policy,
file-picker cancellation, local file failure, and restore confirmation.
Never use cloud/upload language. Backup preserves each vehicle's units and
currency configuration.
