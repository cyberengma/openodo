# Accessibility

- Never communicate reminder state by color alone; use text, icon, and order.
- Every icon action has an accessible label.
- Form errors are associated with fields and announced without losing input.
- Numeric values expose unit and currency in their accessible description.
- Charts include a textual summary and a non-visual data alternative.
- Focus order follows visual/form order.
- Forms scroll to the first error when the keyboard is open.
- Large text, long labels, long notes, narrow screens, and landscape are
  supported without clipping essential actions.
- Light and dark themes preserve contrast and status distinctions.
- Touch targets remain comfortably usable; essential actions are not
  swipe-only.
