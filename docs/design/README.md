# OpenOdo Design Authority

Version 1.0, derived from the approved Sleek project `OpenOdo Mobile`.

This directory is authoritative for UI planning in Slices 06-10. The visual
language is calm, compact, Material 3, teal-led, and offline-first. The
design is phone-first but must expand cleanly on larger screens.

Read `decisions.md` first, then `navigation.md`, the screen specifications,
`components.md`, `states.md`, `accessibility.md`, and `traceability.md`.

The domain remains authoritative for behavior. These documents define how
that behavior is presented, not new business rules.
