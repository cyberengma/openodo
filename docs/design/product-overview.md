# Product Overview

OpenOdo is a private, offline vehicle log for fuel, electric charging,
maintenance expenses, reminders, statistics, and portability. The primary
user owns one or more vehicles and needs a dependable history without an
account, cloud sync, analytics, ads, or network access.

The visual direction is practical and premium: teal primary actions, warm
neutral surfaces, charcoal text, rounded cards, compact tabular metrics, and
clear urgency treatment. Light and dark themes use the same hierarchy.

Each vehicle owns its distance unit, volume unit, energy unit, and currency.
Switching vehicles switches formatting everywhere; canonical stored values
remain metres, millilitres, watt-hours, and integer minor money.

Primary product actions are adding fuel, adding an expense, adding a
reminder, reviewing the dashboard, inspecting history, and exporting or
importing local data.
